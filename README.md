# Spark Store
Nota de Tradução e Desenvolvimento: Esta é uma versão traduzida da documentação original. O desenvolvimento e a manutenção deste projeto são realizados como um hobby pelos membros da comunidade, movidos pelo entusiasmo de melhorar o ecossistema Linux.

# Introdução
Bem-vindo à Spark Store! Esta é uma loja de aplicativos projetada para usuários da plataforma Linux, com o objetivo de resolver os problemas de fragmentação e de difícil obtenção de softwares dentro do ecossistema Linux. Independentemente da sua distribuição Linux, você poderá encontrar pacotes de software adequados aqui.

A quantidade de aplicações nativas para Linux é relativamente limitada, e obter softwares via Wine também pode ser uma tarefa desafiadora. Excelentes kits de desenvolvimento e recursos de ferramentas estão espalhados por várias comunidades e fóruns, tornando difícil para o ecossistema alcançar uma melhoria abrangente.

A construção de um ecossistema não depende de esforços individuais e isolados, mas requer a participação total da comunidade. Somente quando a "faísca" (spark) de cada um se reúne em um só lugar é que se pode acender uma grande fogueira.

Para melhorar essa situação, lançamos a Spark Store. A Comunidade Spark coleta extensivamente pacotes de software para atender às diversas necessidades dos usuários, agrega pequenas ferramentas de alta qualidade e adapta aplicações Wine de forma proativa. Todos os recursos são armazenados em nosso repositório, permitindo que os usuários acessem essas aplicações de maneira conveniente.

# Distribuições Linux suportadas atualmente incluem (mas não se limitam a):
- Arquitetura amd64: deepin 20 / deepin 23 / Ubuntu 20.04 / Ubuntu 22.04 / UOS Home Edition 20 / Debian 11+

- Arquitetura arm64: UOS Professional Edition 1060 / Ubuntu 22.04 / deepin 23

- Arquitetura loong64: deepin 23

Nota Especial: A Spark Store também suporta todas as versões do Ubuntu OS mais recentes que o Ubuntu 22.04, como Ubuntu 22.10, 23.04, 23.10, etc. Além disso, a Spark Store pode se adaptar a outras distribuições Linux além das plataformas listadas; você pode realizar testes de instalação por sua conta.

Aviso Importante: Este software não pode garantir disponibilidade contínua, operação ininterrupta ou o cumprimento de requisitos de desempenho específicos. A comunidade Spark não se compromete com a integridade funcional, estabilidade ou operação livre de erros deste software. Por exemplo, se você planeja usá-lo no UOS Professional Edition (or outras plataformas específicas semelhantes), certifique-se de entender e ativar os recursos do "Modo Desenvolvedor". São necessárias habilidades básicas de solução de problemas (troubleshooting). É importante notar que a comunidade Spark não pode realizar testes extensivos em algumas plataformas especiais. Portanto, o uso do cliente Spark Store nessas plataformas pode levar a vários problemas, como falhas na atualização do sistema ou perda de dados. O uso deste software indica seu entendimento e aceitação de que todos os riscos devem ser assumidos pelo usuário.
